# ☕ Bean-Brew Coffee Website

A modern and visually rich **coffee shop website** built using **HTML, CSS, and JavaScript**.  
Bean-Brew showcases handcrafted coffee, menu items, testimonials, gallery, and contact details with smooth animations and a premium UI.

## ✨ Features
- Responsive multi-section landing page
- Modern hero section with call-to-action
- About section with brand story & social links
- Menu showcase with images and descriptions
- Testimonials slider using Swiper.js
- Image gallery with aesthetic layout
- Contact section with details & form
- Smooth animations and clean UI design
